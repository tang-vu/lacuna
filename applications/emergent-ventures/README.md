# Emergent Ventures application packet

Status: **complete technical draft, not submitted**.

The official [Emergent Ventures application](https://mercatus.tfaforms.net/5099527) was accessible
on 2026-08-25. The first-stage proposal must stand alone, stay under 1,500 words, and must not use
PDF attachments. The current form shows no application fee. The USD 25,000 figure is a draft
funding request, not a cost to apply and not a commitment until the applicant confirms it.

## Files

- `proposal.md`: the main proposal, including marked personal sections that still need the
  applicant's own words.
- `form-fields.md`: copy-ready short answers, budget, and private-field checklist.

## Submission gates

1. Replace the personal-story marker with 150--250 honest words about why the applicant built
   lacuna and can complete this work.
2. Confirm or rewrite the proposed consensus-view answer. It must be the applicant's real view.
3. Confirm six months part-time, roughly 20 hours/week, USD 40/hour, and the USD 25,000 budget.
4. Supply name, email, phone with country code, country, state/province if required, and city only in
   the private form. Do not commit them to this repository.
5. Select the live form's region and topic values; the repository does not guess enumerated options.
6. Personally certify age eligibility, permitted grant use, data-processing consent, and CAPTCHA.
7. Paste the final proposal and verify the live word counter. Do not attach `paper.pdf`; the form
   explicitly says no PDFs.
8. Submit only after final user review, then save the confirmation and a redacted copy in a follow-
   up commit.

OpenAI Codex assisted with inspecting the public form and drafting this packet on 2026-08-25. The
applicant remains responsible for the personal claims, final text, and any disclosure required by
the funder.
